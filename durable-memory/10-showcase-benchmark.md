## 1. Purpose, Catalogue Survey, and Asset Licence Rule

The practical proof that the consolidated `lmvideo` product (`Image`/`Frame`, `Canvas`, `Scene`, `Layout`, `Timeline` with CPU rasterizer + built-in CPU Cycles) has reached visual maturity is its ability to reproduce the iconic classes of imagery demonstrated in:
1. **Blender Demo Files & Splash Gallery** (`https://www.blender.org/download/demo-files/`): surveyed across all 12 upstream categories (*Asset Bundles*, *Blender Splash Artwork* 2.74–5.2, *Hair*, *Simulation*, *Geometry Nodes*, *Grease Pencil*, *EEVEE*, *Rendering*, *Cycles*, *Modeling*, *Animation*, *Physics*).
2. **three.js Official Examples** (`https://threejs.org/examples/`, upstream `examples/files.json`): surveyed across `webgl` (180+ scenes: animation, camera, clipping, geometry, instancing, lights, loaders, materials,pmrem, points, shadowmap), `webgl / postprocessing` (26 passes: 3DLUT, DoF, GTAO/SSAO, outline, Sobel, bloom), `webgl / advanced`, and `webgpu` (caustics, clearcoat, compute particles, procedural city).

### Strict Asset & Reference Licence Policy

Per the owner's licence gate ([09-lmvideo-backlog.md](09-lmvideo-backlog.md) §Phase P & §6.0):
- **Allowed for direct redistribution / `lmctl.com/assets/v1/` caching**: `CC0-1.0`, `MIT`, `BSD-2-Clause`, `BSD-3-Clause`, `Apache-2.0`, `OFL-1.1`, `Bitstream-Vera`, and **`CC-BY-4.0`** (provided exact creator attribution, source URL, SHA-256, and licence text are recorded in the `P.A2`/`P.3` provenance manifest and emitted by `--notices-used`).
- **Excluded from shipping (`CC-BY-SA`, `GPL`, or unverified third-party model licences)**:
  - Many Blender splash files (e.g., *3.5 Cozy Kitchen*, *3.3 Scanlands*, *3.1 Secret Deer*, *2.92 Sinosauropteryx*, *2.77 Racing Car*, *Repeat Zone Flower*) are **`CC-BY-SA`** (ShareAlike copyleft on derivatives), and several `three.js` `examples/models/` assets carry mixed or non-standard notices.
  - **Rule**: We **never** ship `CC-BY-SA` or `GPL` `.blend`/mesh/texture files, and we **never** copy copyrighted reference renders from `blender.org` or `threejs.org` into our repositories. Where a reference scene is `CC-BY-SA`, too large (e.g., 280 MB–1.4 GB open-movie packs), or relies on Blender-internal node graphs, we **author an original procedural `.lms` scene of the same visual archetype** (or use `CC0` / `CC-BY-4.0` assets) and compare against a written visual specification and reference URL.

### 3.2 Benchmark Acceptance Contract (No Copyrighted Renders in Repo)

For each benchmark scene `B01`–`B32`, completion requires:
1. **Self-contained `.lms` script** in the **public peer** (`lmctl-ai/lmvideo`) under `examples/showcase/bench-NN-<slug>.lms` (using only procedural generation or pinned `CC0` / `CC-BY-4.0` assets resolved through `P.1`/`P.6` with SHA-256 verification and `--offline` support).
2. **Committed rendered output** in the **public peer** (`docs/images/showcase/bench-NN-<slug>.png` or `.gif`/`.mp4`) produced by `lmvideo` from an empty working directory (`lmctl autorun https://raw.githubusercontent.com/lmctl-ai/lmvideo/main/examples/showcase/bench-NN-<slug>.lms`).
3. **Side-by-side Public README / Scoreboard Table entry** (`lmctl-ai/lmvideo/README.md` and `docs/showcase-benchmark.md`) containing:
   - Our committed rendered image (`<img src="docs/images/showcase/bench-NN-<slug>.png" width="420">`),
   - A structured technical description of the reference scene, its clickable upstream URL (`blender.org` or `threejs.org`), the visual phenomenon being verified (e.g., *"Dielectric refraction + volume absorption + internal reflections on lathe geometry"*), measured CPU render time / peak RSS, and the exact `lmctl autorun` one-liner.
   - **Zero copied third-party reference JPEGs/PNGs** in the Git tree.
4. **Quantitative Regression Gate**:
   - Same-environment reruns match pinned SHA-256 (for `raster`) or `SSIM >= 0.99` (for `cycles` with fixed seed and OIDN);
   - `raster` vs `cycles` material handoff scenes (`B06`, `B27`) verify base-color and silhouette parity (`SSIM >= 0.85` on diffuse/matte regions, with documented GI/specular differences).
